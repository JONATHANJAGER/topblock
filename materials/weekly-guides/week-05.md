### Session 1: Operating system
**Definition:** Software that manages a computer's hardware and applications
**Everyday example:** A warehouse manager coordinates people and equipment
**Business scenario:** An AGL trainee is moving between folders to collect safe simulation reports.
**Guided actions:**

5. Save a sanitized screenshot, diagram or text note in your course project folder.

### Session 2: Shell
**Definition:** A program that accepts commands and starts the requested tasks
**Everyday example:** A dispatcher issues instructions through a single control terminal
**Business scenario:** An AGL trainee is moving between folders to collect safe simulation reports.
**Guided actions:**
1. Open Terminal on macOS/Linux or PowerShell on Windows.
2. Run pwd (or Get-Location) to locate the current directory, then list files with ls (or Get-ChildItem).
3. Create a folder named cyber-lab, enter it, and record commands in your notes.
4. Create a harmless file, inspect its permissions; do not edit administrative system files.
**Check understanding:**
- Which term describes this idea: a program that accepts commands and starts the requested tasks?
- Which practical step best demonstrates shell in this lesson?
**Project action:** Open a terminal and type pwd or Get-Location
