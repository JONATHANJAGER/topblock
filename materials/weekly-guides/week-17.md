**Milestone:** Write an AGL rules-of-engagement document and scope matrix

### Session 1: Written authorization
**Definition:** Permission specifying the exact systems and activities allowed
**Everyday example:** A maintenance crew needs a signed work order for restricted equipment
**Business scenario:** A consulting team has written approval to examine a deliberately vulnerable test application.
**Guided actions:**
1. Start with the fictional AGL situation: A consulting team has written approval to examine a deliberately vulnerable test application.
2. Define written authorization in one sentence: Permission specifying the exact systems and activities allowed
3. Carry out this small, authorized activity: Define two approved lab systems and a stop condition.
4. Record what you expected to observe, what actually happened and the difference, if any.
5. Save a sanitized screenshot, diagram or text note in your course project folder.
**Check understanding:**
- Which term describes this idea: permission specifying the exact systems and activities allowed?
- Which practical step best demonstrates written authorization in this lesson?
**Project action:** Define two approved lab systems and a stop condition
